# RVL claim and decision record — after the first scored code benchmark

**Question:** When must trusted verification catch up with optimizer-induced
policy movement relative to the verifier's unresolved error directions?
The target venue or presentation category is not evidence.

| Layer | Established observation or result | Allowed claim | Missing evidence |

## Three priority tasks

1. **Acquire an identifiable failure regime, outcome-blind.** Use the pinned
   MBPP+ parquet and the original pilot's prompt-only hash ordering: ranks
   8–39 for development and 40–71 for final evaluation, 16 IID model
   candidates per task. The scored pilot informed this sample-size decision,
   so the development set is not wholly independent discovery. Commit explicit
   task IDs and prompt hashes before generating programs. Keep every task,
   including tasks with no correct candidate, in primary analyses.
2. **Derive a trajectory-conditioned information frontier.** For an
   independently calibrated error class, bound labels required to certify
   an *adaptively proposed* shift, with a matching lower bound for an
   endogenous sequence. The existing metric covering bracket is classical;
   the cheap-feature Lipschitz assumption fails on observed tasks. State
   misspecification explicitly and quantify its cost to useful progress.
3. **Test equal-information timing and transfer.** Compare early/uniform/late
   using identical ordered six-source streams; report a separate fixed
   32-draw arm. Freeze warning thresholds and cost/failure decisions on
   development tasks before opening heldout trusted rewards. If fewer than
   five heldout task IDs have later-onset failures under fixed timing, call
   the boundary underidentified. Compare residual movement, max log ratio,
   KL and exposure without picking a winner on the heldout outcomes.

## Alternative explanations and scope

- Timing can act through cumulative exposure to different fitted scores.
  The composed-block identity and identical final label sets allow a check.
- All-zero reward tasks and round-one failures cannot demonstrate lag from
  *later* staleness. Keep them visible without post-hoc exclusions.
- Adaptive source queries change label identity. Only an identical ordered
  source stream isolates timing at identical final information.
- Safe projection can concentrate on audited sources. Report their mass and
  effective support alongside gain and trusted-label cost.
- Reweighting a static candidate bank does not create model capability.

Proceed to a theory-plus-experiment manuscript only if heldout later-onset
failure is identifiable, a development-frozen predictor or controller
transfers at matched actual label cost, and its error assumptions survive
prospective calibration. Otherwise publish the narrower conditional theory
with negative transfer or redesign as a *new* study before seeing new
outcomes. A toy phase plot or a classical covering proof alone does not
establish an Oral/Spotlight result.
