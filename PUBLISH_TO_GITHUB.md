# Publishing this repository to GitHub

This repository was generated locally and has not been pushed to a GitHub account.

## Option A — GitHub web interface

1. Create a new empty repository on GitHub, for example `recursive-verification-lag`.
2. Do not initialize it with a README if you want to preserve this repository exactly.
3. In this directory, run:

```bash
git init
git add .
git commit -m "Initial research release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/recursive-verification-lag.git
git push -u origin main
```

## Option B — GitHub Desktop

1. Extract the ZIP.
2. Open the folder in GitHub Desktop.
3. Create the repository from the existing folder.
4. Publish repository.

## Before making it public

- Replace or add author/contact information if desired.
- Decide on a software/content license. No license is included by default.
- Check whether all research notes should be public; the `notes/` directory contains detailed working history and failed directions.
- Optionally make the repository private first and send the link in internship applications.
