# Research notes

This directory preserves the dated development record and focused theory notes. Use the root [README](../README.md) and [documentation index](../docs/README.md) for the current project summary. A note records what was proposed or observed at its date; it is not automatically the current plan or a confirmed result.

- [Master research record](master_research_record.md): full running ledger of questions, derivations, decisions, and corrections.
- [Progress archive](progress/README.md): dated experiment updates, in chronological order.
- [Theory-note index](theory/README.md): focused derivations and audits that extend the concise [theory ledger](../docs/theory.md).

Preserve original protocols, failures, and negative outcomes when adding new work. When a later analysis corrects an earlier claim, link both records and state the correction in the newer document.
